Hermes CC - Privacy policy

Last updated: October 24, 2026

Who uses it

Hermes CC is a personal, non-commercial tool built and used by one person (the owner). Only the owner's own Google accounts authorize it. It is not offered to anyone else.

Google user data it accesses

  • Gmail: messages, threads, labels and change history (read). Applying labels, archiving, creating drafts and sending happen only after the owner approves each action.
  • Google Calendar: the list of calendars and the events on calendars the owner owns (read). Creating, changing or deleting events happens only after the owner approves.

How the data is used

Only to provide features to the owner: classifying his email, tracking pending items, deadlines and recurring payments, and carrying out actions he approves. The data is never sold, never used for advertising and never used to train AI models.

Where it is stored

On the owner's own computer, in an encrypted database. OAuth credentials are kept in the owner's password manager. This website stores nothing.

Who else receives it

Google user data is shared only with service providers the owner uses to run Hermes CC for himself, and only as needed for these features: AI model APIs (currently Anthropic) to classify messages and draft replies, and notification services (such as Telegram or Pushover) to send him reminders. No one else receives it.

Limited Use

Hermes CC's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The data stays on the owner's computer until he deletes it. Access can be revoked at any time at myaccount.google.com/connections; revoking it cuts off Hermes CC's access to that account.
